OCaml projects that I started
=============================

This is collection of links to notable general-purpose OCaml-related projects
that I started either on my own time or while employed, and are
available to the world for free.

* [Testo](https://semgrep.github.io/testo/): a test framework for
  OCaml that supports parallel runs, Unix and Windows,
  stdout/stderr snapshots, timeouts, etc.
* [ATD](https://atd.readthedocs.io/): flexible and expressive type definition
  language suitable for exchanging JSON data safely across
  applications written in different languages including
  C++, D, Java, OCaml, Python, Scala, TypeScript.
* [Yojson](https://github.com/ocaml-community/yojson): a JSON parser
  and pretty-printer. Used by ATD,
  [ppx_deriving_yojson](https://github.com/ocaml-ppx/ppx_deriving_yojson),
  and various other projects.
* [cppo](https://github.com/ocaml-community/cppo): a C-style
  preprocessor for OCaml.
* [mikmatch](https://mjambon.github.io/mjambon2016/micmatch.html)
  ([GitHub](https://github.com/mjambon/mikmatch))
  (2004, defunct):
  extension of OCaml's ML-style pattern-matching syntax with
  regexps. Was based on Camlp4 which since has fallen from grace.
